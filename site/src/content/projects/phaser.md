## 一句话定位

Phaser 是最流行的开源 HTML5 游戏框架，用 JavaScript/TypeScript 就能开发能在浏览器和移动端运行的 2D 游戏，提供物理引擎、精灵、动画、输入、音频等游戏开发所需的完整能力，是 Web 游戏开发的首选。

## 诞生背景

2013 年由 Richard Davey 创建。随着 HTML5 的 Canvas 和 WebGL 成熟，浏览器具备了跑游戏的能力，但直接用底层 API 开发游戏繁琐。Phaser 封装出一套完整易用的游戏框架，让 Web 开发者能快速做出 2D 游戏。

## 核心架构

- **Canvas / WebGL 渲染**：自动选择最优渲染方式
- **物理引擎**：内建 Arcade（轻量）和 Matter.js（复杂物理）
- **场景（Scene）系统**：组织游戏的不同状态/关卡
- **精灵与动画**：Sprite、Tween、粒子等游戏元素
- **跨平台**：一套代码跑在浏览器、可打包到移动端

## 关键设计决策

1. **拥抱 Web 技术**：用 JS + Canvas/WebGL，让海量 Web 开发者零门槛进入游戏开发。
2. **电池全含**：物理、动画、输入、音频一应俱全，专注做游戏而非造轮子。
3. **2D 专精**：聚焦 2D 游戏（而非贪大做 3D），把这个领域做到简单好用。

## 生态位置

HTML5/Web 2D 游戏框架的领导者。竞品：PixiJS（更底层渲染）、Cocos（跨平台、中国流行）、以及做 3D 的 Three.js/Babylon.js。与桌面/主机级引擎（Unity、Unreal、Godot）路线不同，Phaser 专注轻量的 Web 2D 游戏、H5 小游戏。

## 我的评价

Phaser 的价值在于降低了游戏开发的门槛——它让任何会 JavaScript 的人都能在浏览器里做出游戏，无需学习庞大的专业引擎。它专注 Web 2D 的克制也很聪明：不与 Unity/Unreal 正面竞争，而是在"轻量 Web 游戏、H5 小游戏、教学"这个细分领域做到最好。它再次说明：**降低门槛 + 场景专注，是开源工具赢得广泛使用的常见配方。**
