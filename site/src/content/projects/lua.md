## 一句话定位

Lua 是一门极致轻量、快速、易嵌入的脚本语言，其解释器仅数百 KB，专为"嵌入到宿主程序中提供脚本能力"而设计，广泛用于游戏（魔兽世界、Roblox）、Nginx（OpenResty）、Redis 等，是嵌入式脚本领域的王者。

## 诞生背景

1993 年由巴西 PUC-Rio 大学团队创造。当时需要一门能嵌入到应用中、让非程序员也能编写配置和逻辑的轻量语言。Lua（葡萄牙语"月亮"）以极小的体积、简洁的语法和与 C 的无缝集成，完美满足了这一需求。

## 核心架构

- **极致轻量**：完整解释器仅几百 KB，可塞进任何程序
- **易嵌入**：为嵌入 C/C++ 程序而设计，C API 简洁强大
- **快速**：LuaJIT 更是脚本语言性能标杆
- **元表（Metatable）**：用元表机制灵活实现 OOP、继承等
- **协程**：内建协作式多任务

## 关键设计决策

1. **为嵌入而生**：从设计起就以"嵌入宿主程序"为目标，而非独立通用语言。
2. **极致精简**：保持语言核心极小，靠元表等少量强大机制实现灵活性。
3. **与 C 共生**：无缝的 C 互操作，让宿主程序能轻松暴露能力给脚本。

## 生态位置

嵌入式脚本语言的绝对代表。游戏（魔兽世界插件、Roblox、众多引擎）、Web（OpenResty/Nginx）、数据库（Redis 脚本）、嵌入式设备处处可见。竞品：其他嵌入式脚本方案，但 Lua 在"轻量 + 嵌入"这一点上几乎无可替代。

## 我的评价

Lua 是"专注定位"的极致典范——它不贪图成为通用语言，只把"嵌入式脚本"一件事做到极致，于是在这个领域几乎无人能敌。它的小巧不是能力不足，而是刻意的设计哲学：**小到可以嵌入任何地方，就是它最大的力量**。从魔兽世界到 Redis 到嵌入式设备，它证明了一门语言不必大而全，只要在自己的生态位做到不可替代，就能无处不在。
