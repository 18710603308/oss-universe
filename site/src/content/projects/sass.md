## 一句话定位

Sass（Syntactically Awesome Style Sheets）是最成熟、最流行的 CSS 预处理器，给原生 CSS 带来了变量、嵌套、混入（mixin）、函数、模块化等编程能力，让编写和维护大型样式表变得高效可控，深刻影响了 CSS 的演进。

## 诞生背景

2006 年诞生。原生 CSS 缺乏变量、嵌套、复用机制，大型项目样式冗长、重复、难维护。Sass 引入编程语言的特性来"增强"CSS，写完再编译回标准 CSS，极大提升了样式开发的工程化水平。

## 核心架构

- **变量**：定义颜色、尺寸等可复用值（原生 CSS 后来才有变量）
- **嵌套**：按 DOM 结构嵌套书写选择器，更直观
- **Mixin 与函数**：复用样式片段、封装逻辑
- **模块化（@use/@import）**：拆分并组合样式文件
- **编译**：Sass 代码编译为标准 CSS（Dart Sass 为现行主实现）

## 关键设计决策

1. **给 CSS 加编程能力**：变量、函数、mixin 让样式可复用、可抽象，告别复制粘贴。
2. **编译回标准 CSS**：作为预处理层，产物仍是浏览器直接认的 CSS，无运行时开销。
3. **务实增强而非替代**：不推翻 CSS，而是在其上做工程化增强，平滑易采纳。

## 生态位置

CSS 预处理器的事实标准。竞品/同类：Less、Stylus（同代预处理器）、PostCSS（后处理，可组合插件）。它的许多特性（变量、嵌套）已被原生 CSS 逐步吸收。与 Tailwind（原子化、另一种范式）路线不同。

## 我的评价

Sass 是"工程化改造存量技术"的经典案例——它没有取代 CSS，而是给这门缺乏编程能力的语言"打补丁式增强"，让大型样式的维护成为可能。它的深远影响体现在：**它验证过的特性（变量、嵌套），后来被原生 CSS 标准吸收了**。这是开源工具的一种高级贡献：*先行探索出好特性，最终推动底层标准的进化*——工具本身或许会淡出，但它推动的进步会永久留存。
