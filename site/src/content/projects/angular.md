## 一句话定位

Angular 是 Google 主导的企业级前端框架（指 2016 年完全重写的 Angular 2+，区别于 AngularJS），以 TypeScript 优先、内置全套能力（路由、表单、HTTP、DI）和强约定，成为大型复杂前端应用的完整解决方案。

## 诞生背景

AngularJS（1.x）开创了前端框架时代但架构老化。2016 年 Google 用 TypeScript 完全重写为 Angular 2+，与旧版不兼容。它面向大型团队，提供"框架级"的完整方案而非"库"。

## 核心架构

- **TypeScript 优先**：从设计之初深度依赖 TS 类型系统
- **组件 + 模块**：组件化 + NgModule 组织应用
- **依赖注入（DI）**：内置强大的 DI 系统（借鉴后端）
- **RxJS 响应式**：深度集成响应式编程
- **全家桶**：路由、表单、HTTP、CLI、测试一应俱全

## 关键设计决策

1. **框架而非库**：提供从路由到状态到构建的完整方案，强约定减少选型，适合大团队。
2. **TypeScript + DI**：把后端的类型与依赖注入引入前端，利于大型代码库的可维护性。
3. **完全重写**：为现代化不惜与 AngularJS 断代，体现"长期正确优于短期兼容"的取舍。

## 生态位置

前端三大框架之一（React/Vue/Angular）。以企业级、强约定见长，学习曲线较陡。React 更灵活、Vue 更渐进、Angular 更完整。在大型企业、银行等复杂应用中占有率高。

## 我的评价

Angular 代表了前端框架的一种哲学：**用强约定和完整方案换取大型团队的一致性与可维护性**。它不如 React 灵活、不如 Vue 平缓，但在需要几百人协作的超大型应用里，"框架替你做好决定"反而是优势。它与 React 的对比，本质是"约定 vs 自由""完整 vs 组合"的永恒权衡——没有最好，只有最合适的场景。
