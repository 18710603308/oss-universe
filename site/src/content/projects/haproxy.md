## 一句话定位

HAProxy（High Availability Proxy）是久经考验的高性能 TCP/HTTP 负载均衡器与反向代理，以极致的稳定性、性能和精细的流量控制著称，是无数大型网站流量入口的可靠选择。

## 诞生背景

2001 年由 Willy Tarreau 创建。随着网站流量增长，单台服务器扛不住，需要把请求可靠地分发到多台后端。HAProxy 专注把"负载均衡"这一件事做到极致的稳定与高效。

## 核心架构

- **事件驱动 + 单进程多线程**：高效处理海量并发连接
- **L4/L7 负载均衡**：既能按 TCP（四层）也能按 HTTP（七层）分发
- **健康检查**：自动剔除不健康的后端
- **丰富的负载均衡算法**：轮询、最少连接、源地址哈希等
- **可观测性**：详尽的统计页面与指标

## 关键设计决策

1. **专注负载均衡**：不做 Web 服务器的全部，只把"高可用流量分发"做到极致。
2. **稳定与性能优先**：以"多年零宕机"级别的可靠性著称，是生产环境的定心丸。
3. **精细的流量控制**：丰富的 ACL、算法与健康检查，满足复杂分发需求。

## 生态位置

负载均衡领域的老牌标杆。竞品/同类：Nginx（也能做 LB，但更偏 Web 服务器）、Envoy（云原生数据面）、Traefik（动态服务发现）、云厂商 LB。在需要极致稳定的四/七层负载均衡场景，HAProxy 仍是首选之一。

## 我的评价

HAProxy 是"把一件事做到极致"的又一典范——它不追求大而全，二十余年就专注于"可靠地分发流量"，靠稳定性赢得了生产环境的信任。它与 Nginx、Envoy、Traefik 的并存说明：流量入口这一层，会因"侧重稳定 / 侧重 Web / 侧重云原生 / 侧重动态"而分化出不同的专精工具。选型的关键永远是场景匹配。
