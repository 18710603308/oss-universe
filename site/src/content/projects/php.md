## 一句话定位

PHP 是专为 Web 开发而生的服务端脚本语言，以极低的上手门槛和"嵌入 HTML"的直接性席卷了互联网早期，至今仍驱动着全球大半网站（WordPress、维基百科、Facebook 早期都用它）。

## 诞生背景

1994-1995 年由 Rasmus Lerdorf 创造，最初只是管理个人主页的一组脚本（Personal Home Page）。它诞生在 Web 爆发的前夜，用"把代码直接写进 HTML"的简单模式，让无数人快速做出了动态网站。

## 核心架构

- **嵌入 HTML**：`<?php ?>` 直接混写在 HTML 中，即写即用
- **请求生命周期**：每个请求独立执行，天然无状态、易水平扩展
- **丰富的 Web 内建**：表单、会话、数据库访问开箱即用
- **Composer**：现代包管理与依赖生态
- **持续现代化**：PHP 7/8 大幅提升性能，引入类型、JIT

## 关键设计决策

1. **为 Web 优化的执行模型**：请求隔离、无共享状态，简单且天然可扩展。
2. **极低门槛**：嵌入 HTML、即改即见，让非专业者也能做动态网站。
3. **务实演进**：从被诟病的早期设计，通过 PHP 7/8 大幅现代化（性能、类型系统）。

## 生态位置

Web 后端的元老级语言。生态：WordPress（占全球 40% 网站）、Laravel（现代框架）、Symfony、Composer。竞品：Node.js、Python、Ruby、Go。虽被唱衰多年，但凭 WordPress 与 Laravel 生态依然稳固。

## 我的评价

PHP 常被程序员调侃，但它的历史贡献不容否认——它用"最低的门槛"让 Web 开发平民化，直接推动了互联网内容的爆发。它也是"务实演进"的样本：早期设计饱受批评，却靠 PHP 7/8 的性能与类型现代化重获新生。它证明了：**生态和易用性带来的惯性，足以让一门语言穿越唱衰、长期存活**。
