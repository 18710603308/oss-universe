## 一句话定位

Ruby on Rails 是由 DHH（David Heinemeier Hansson）创造的全栈 Web 框架，以"约定优于配置"和"不要重复自己（DRY）"两大理念，让开发者以惊人的速度构建数据库驱动的 Web 应用，深刻影响了此后一整代 Web 框架的设计。

## 诞生背景

2004 年从 Basecamp 项目中提取开源。当时 Web 开发充斥着繁琐配置和样板代码。Rails 提出"约定优于配置"：只要遵循约定，框架就自动帮你搞定大量工作，把 Web 开发的效率提升到了前所未有的高度。

## 核心架构

- **约定优于配置**：遵循命名/结构约定，零配置即可运行
- **MVC 架构**：清晰的模型-视图-控制器分层
- **Active Record**：优雅的 ORM，对象即数据库记录
- **脚手架（Scaffold）**：一条命令生成 CRUD 骨架
- **DRY 原则**：消除重复，一处定义处处复用

## 关键设计决策

1. **约定优于配置**：用合理的默认约定消灭配置，这一理念影响了无数后续框架（Ember、Spring Boot 等）。
2. **开发者幸福感**：DHH 明确把"让开发者愉悦"作为设计目标，优雅的 API 是核心追求。
3. **全栈一体**：从数据库到视图一整套，让小团队也能快速交付完整产品。

## 生态位置

"约定优于配置"范式的开创者，影响极为深远。GitHub、Shopify、Airbnb 早期都用它。竞品：Django（Python 同类）、Laravel（PHP，深受 Rails 启发）、Phoenix（Elixir）。它定义了"高效全栈框架"的模板。

## 我的评价

Rails 的历史地位怎么强调都不过分——它提出的"约定优于配置"是软件设计的一次思想飞跃，此后 Django、Laravel、Spring Boot 等无不受其影响。它还开创性地把"开发者幸福感"当作一等目标。它证明了：**一个好框架不只是功能集合，更是一套关于"如何优雅高效地工作"的哲学主张**。理解 Rails，就理解了现代全栈框架的思想源头。
