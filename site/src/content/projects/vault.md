## 一句话定位

Vault 是 HashiCorp 开源的机密（secrets）管理系统，用于安全地存储、访问和分发 API 密钥、密码、证书等敏感信息，并支持动态生成短生命周期凭证，是云原生时代的安全基石。

## 诞生背景

2015 年发布。微服务和云环境中，密钥散落在配置文件、环境变量、代码里，泄露风险极高。Vault 提出集中管理机密，并用"动态密钥"（用完即焚）替代长期静态密钥。

## 核心架构

- **Secrets Engine**：管理不同类型机密（KV、数据库、PKI 证书、云凭证）
- **动态密钥**：按需生成短期有效的凭证，自动过期回收
- **身份认证**：多种 auth 方法（K8s、LDAP、云 IAM 等）
- **加密即服务**：应用无需自己实现加密，调用 Vault 的 Transit 引擎
- **审计日志**：所有访问可追溯

## 关键设计决策

1. **动态密钥**：变长期静态凭证为"用完即焚"的短期凭证，大幅缩小泄露窗口。
2. **集中管理 + 细粒度授权**：统一存储，按策略精确控制谁能访问什么。
3. **加密即服务**：把加密能力抽象为服务，应用无需处理密钥。

## 生态位置

密钥管理领域标杆。与 Terraform、K8s、CI/CD 深度集成。2023 年同样改用 BSL 协议，社区 fork 出 OpenBao（Linux 基金会）。

## 我的评价

Vault 的核心洞察是「静态密钥是安全的原罪」——长期不变的密钥一旦泄露就是灾难。它用"动态生成、短期有效、自动回收"把安全模型从"守住秘密"转向"让秘密不值得偷"。这种"从根本上消除风险来源"而非"层层设防"的思路，是安全设计的高级境界。
