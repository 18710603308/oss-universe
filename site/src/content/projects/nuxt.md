## 一句话定位

Nuxt 是基于 Vue 的全栈元框架，为 Vue 提供服务端渲染（SSR）、静态生成、文件路由、自动导入、服务端 API 等开箱即用能力，是 Vue 生态中构建生产级应用的首选，地位相当于 React 阵营的 Next.js。

## 诞生背景

2016 年发布，与 Next.js 几乎同期。纯 Vue 是客户端渲染，缺少 SSR、路由、构建等生产级工程化能力。Nuxt 借鉴 Next.js 理念，为 Vue 补齐这套"约定优于配置"的全栈方案。

## 核心架构

- **文件系统路由**：pages 目录结构即路由
- **多渲染模式**：SSR、SSG、SPA、混合渲染
- **自动导入**：组件、组合式函数无需手动 import
- **Nitro 服务引擎**：跨平台部署（Node、边缘、Serverless）
- **模块生态**：丰富的官方与社区模块

## 关键设计决策

1. **Vue 的 Next.js**：把 Next.js 验证过的元框架范式带入 Vue 生态。
2. **约定优于配置**：文件路由、自动导入等约定大幅减少样板代码。
3. **Nitro 跨平台部署**：一套代码可部署到 Node、Serverless、边缘等多种环境。

## 生态位置

Vue 全栈元框架的绝对主流，与 Next.js（React）分庭抗礼。Vue 阵营的生产级应用标配。竞品：Next.js（React）、SvelteKit（Svelte）、Astro（内容优先，本站所用）。

## 我的评价

Nuxt 与 Next.js 的"平行演进"很有意思——同样的元框架理念（文件路由、SSR、约定优于配置）在 React 和 Vue 两个生态各自开花。这说明好的架构思想会跨生态传播、被反复验证。它也印证了前端的一个规律：当一个 UI 库足够流行，围绕它的"元框架"就会应运而生，把库补全为完整的应用开发方案。
