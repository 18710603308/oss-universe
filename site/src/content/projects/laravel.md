## 一句话定位

Laravel 是 PHP 生态中最流行、最优雅的全栈 Web 框架，深受 Rails 启发，用富有表现力的语法和丰富的内建功能（ORM、路由、队列、认证等），把 PHP 开发体验提升到了全新高度，自称"为 Web 工匠打造的框架"。

## 诞生背景

2011 年由 Taylor Otwell 创建。当时 PHP 虽普及但框架体验参差，缺少像 Rails 那样优雅高效的方案。Laravel 借鉴 Rails 的"约定优于配置"理念，结合 PHP 特性，为 PHP 带来了现代、愉悦的开发体验。

## 核心架构

- **Eloquent ORM**：优雅的 Active Record 风格数据库操作
- **Artisan CLI**：强大的命令行工具，脚手架/迁移/任务
- **Blade 模板**：简洁的模板引擎
- **丰富内建**：路由、队列、任务调度、认证、缓存开箱即用
- **生态繁荣**：Forge、Vapor、Nova、Livewire 等官方/社区工具

## 关键设计决策

1. **开发者体验优先**：追求"优雅、富表现力"的 API，让写 PHP 变成享受。
2. **约定优于配置**：借鉴 Rails，用合理默认减少配置负担。
3. **电池全含**：队列、认证、调度等常用能力全内建，快速交付完整产品。

## 生态位置

PHP Web 框架的绝对领导者，让"现代 PHP 开发"成为可能。它与 WordPress（PHP 的 CMS 霸主）一起支撑着 PHP 生态的活力。设计理念上是 Rails 在 PHP 世界的精神继承者。竞品：Symfony（Laravel 部分组件即基于它）。

## 我的评价

Laravel 是"体验驱动"框架的又一佳例——它证明了即使是常被唱衰的 PHP，配上一个足够优雅的框架，也能带来一流的开发体验。它和 Rails 的血缘关系（约定优于配置、开发者幸福感）也说明：**好的设计理念会跨越语言边界传播**。Laravel 与 PHP 7/8 的现代化一起，让 PHP 生态在"过时"的唱衰声中始终保持着旺盛生命力。
