## 一句话定位

Node-RED 是基于流的可视化编程工具，用浏览器里拖拽"节点"、连线成"流"的方式编排逻辑，把设备、API、服务连接起来，无需写多少代码就能构建自动化流程，是物联网（IoT）和事件驱动编排领域的经典低代码工具。

## 诞生背景

2013 年由 IBM 开源（现属 OpenJS 基金会）。物联网场景需要把各种设备、传感器、API、服务连接编排，但让硬件工程师或非专业开发者写代码门槛高。Node-RED 用可视化的"节点连线"范式，让流程编排变得直观可拖拽。

## 核心架构

- **基于流的编程**：拖拽节点、连线成流，数据在节点间流动
- **丰富节点库**：设备、协议（MQTT/HTTP）、函数、数据库等海量节点
- **浏览器编辑器**：可视化编辑 + 一键部署
- **Node.js 运行时**：底层跑在 Node.js 上，可用 JS 写自定义节点
- **社区节点生态**：npm 上数千个社区贡献节点

## 关键设计决策

1. **可视化流编程**：用拖拽连线取代写代码，让非专业开发者也能编排复杂流程。
2. **一切皆节点**：把设备、协议、逻辑都抽象成可连接的节点，组合即成应用。
3. **建于 Node.js**：底层用 JS，既能可视化又能在节点里写代码，灵活兼顾。

## 生态位置

物联网/自动化编排的经典工具。与 n8n（更偏 SaaS API 自动化）、Home Assistant（智能家居）、Zapier（商业）在"连接与自动化"领域各有侧重。Node-RED 尤其擅长 IoT、边缘设备、协议桥接场景。

## 我的评价

Node-RED 是"可视化编程"落到实处的成功案例——可视化编程常被诟病"玩具化、难扩展"，但 Node-RED 找到了它真正闪光的场景：物联网的流程编排。在这里，"拖拽连线"恰好匹配了"把设备和服务连起来"的心智模型，而底层 Node.js 又保证了可扩展性。它印证了：**低代码/可视化不是万能，但在匹配的场景下，它能极大地扩展"谁能创造软件"的边界。**
