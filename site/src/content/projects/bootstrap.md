## 一句话定位

Bootstrap 是 Twitter 开源的响应式 CSS 框架，提供栅格系统、预制组件和一致的视觉风格，让开发者无需从零写 CSS 就能快速搭建美观、跨设备适配的网页，是历史上最流行的前端 UI 框架。

## 诞生背景

2011 年由 Twitter 内部工具开源。当时前端缺乏统一的 UI 规范，每个项目都在重复造样式轮子，且响应式（适配手机/桌面）繁琐。Bootstrap 用一套标准化的栅格 + 组件，把"快速做出像样的响应式页面"变成现实。

## 核心架构

- **12 列栅格系统**：响应式布局的核心，按屏幕尺寸自适应
- **预制组件**：按钮、导航、卡片、模态框、表单等开箱即用
- **响应式断点**：一套类适配手机到桌面
- **SCSS 可定制**：通过变量定制主题
- **JS 插件**：下拉、轮播、折叠等交互组件

## 关键设计决策

1. **栅格系统**：把响应式布局标准化为 12 列栅格，极大简化了跨设备适配。
2. **组件化 UI**：提供成套预制组件，"拼装"即可成页面，大幅提速。
3. **约定统一**：一套类名规范，团队协作一致性强。

## 生态位置

历史上最流行的 CSS 框架，普及了"响应式设计"和"组件化 UI"的理念。随着 Tailwind（原子化）和组件库（Ant Design/MUI）兴起而热度下降，但仍是快速原型和后台系统的常见选择。竞品：Tailwind CSS、Bulma、Foundation。

## 我的评价

Bootstrap 是"UI 标准化"的启蒙者——它诞生前，网页样式是各自为战的手工活；它之后，"响应式栅格 + 组件"成了前端的通用语言。它与 Tailwind 的时代交替也很有意思：Bootstrap 提供"现成组件"（高层抽象），Tailwind 提供"原子工具类"（低层自由）——这正是"预制 vs 组装"哲学在 CSS 领域的又一次体现。
