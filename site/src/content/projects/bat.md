## 一句话定位

bat 是用 Rust 编写的 `cat` 增强替代品，在查看文件内容时提供语法高亮、Git 修改标记、行号和自动分页，让在终端里阅读代码和文本变得赏心悦目，是现代命令行体验升级的又一代表。

## 诞生背景

2018 年同样由 sharkdp 开发。`cat` 只是把文件内容原样打印，看代码时没有高亮、没有行号，体验平淡。bat 保留 cat 的核心用途，但叠加了阅读代码时真正有用的增强，让"在终端看文件"从将就变成享受。

## 核心架构

- **语法高亮**：支持数百种语言的高亮
- **Git 集成**：在行号旁标记新增/修改的行
- **行号 + 分页**：自动带行号，长文件自动分页
- **主题丰富**：多种配色主题可选
- **兼容 cat**：可无缝替代 cat，也能作为其他工具的高亮器

## 关键设计决策

1. **增强而非取代用途**：保留 cat "看文件"的核心用途，只叠加高亮/行号等阅读增强。
2. **面向读代码优化**：语法高亮 + Git 标记，精准服务开发者的高频场景。
3. **可组合**：能作为 man、fzf 等工具的高亮后端，融入工具链。

## 生态位置

现代 Rust CLI 家族成员（与 fd、ripgrep、eza、zoxide 同属"重造经典工具"浪潮，多出自 sharkdp）。常被配置进现代终端配置（配合 fzf 预览、作为 man 的分页器等），是打造舒适终端环境的常客。

## 我的评价

bat 完美诠释了"体验升级"的价值——`cat` 半个世纪都够用，但"够用"不等于"好用"。bat 只是加了高亮和行号这些看似微小的改进，就让每天无数次的"看文件"操作变得愉悦。它和 fd、eza 等一起证明：**在人人都习以为常的地方做体验升级，累积起来就是显著的幸福感提升**——这是这批 Rust 工具广受喜爱的根本原因。
