## 一句话定位

jQuery 是 2006 年发布的 JavaScript 库，用简洁的 `$()` 语法统一了 DOM 操作、事件处理和 AJAX，抹平了当年惨烈的浏览器兼容性差异，曾长期是几乎每个网站的标配，是一代前端开发者的启蒙。

## 诞生背景

2006 年由 John Resig 发布。当时各浏览器 API 千差万别（IE 尤其难缠），原生 DOM 操作繁琐且不兼容。jQuery 用统一简洁的 API 屏蔽了这些差异，让"写一次到处能跑"成为可能。

## 核心架构

- **`$()` 选择器**：用 CSS 选择器语法选中元素，极其直观
- **链式调用**：`$(el).addClass().fadeIn()` 流畅操作
- **跨浏览器抹平**：统一封装各浏览器的 API 差异
- **AJAX 封装**：简化异步请求（`$.ajax`）
- **插件生态**：庞大的 jQuery 插件生态

## 关键设计决策

1. **抹平浏览器差异**：把开发者从浏览器兼容地狱中解放，这是它风靡的根本原因。
2. **极简 API**：`$` + 链式调用，让 DOM 操作简单到人人可用。
3. **渐进增强**：可在任意页面局部引入，无需框架式重构。

## 生态位置

历史上最流行的 JS 库（现由 OpenJS 维护）。随着浏览器 API 标准化（querySelector、fetch）和 React/Vue 声明式框架兴起而退居二线，但至今仍有海量遗留站点在用。它是前端从"命令式 DOM"走向"声明式框架"的关键过渡。

## 我的评价

jQuery 是一座值得铭记的里程碑——它解决了那个时代最痛的问题（浏览器兼容），并用极简 API 启蒙了一代前端。它的"式微"也极具启发：当浏览器原生 API 标准化（它推动了这一标准化）、当声明式框架兴起，它的历史使命便完成了。**最好的工具，有时会因为成功地推动了标准而让自己变得不再必要**——这是一种伟大的谢幕。
