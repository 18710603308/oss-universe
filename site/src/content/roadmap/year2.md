## 目标

从「会用」进阶到「读懂源码」并「参与贡献」，每季度深耕一个纵深领域。

## 季度安排

- **Q1 分布式系统**：etcd(Raft) / TiKV / NATS
- **Q2 中间件与网关**：Nginx / Envoy / APISIX
- **Q3 AI 基础设施**：PyTorch / vLLM / LangChain
- **Q4 可观测性**：OpenTelemetry / Grafana / Loki

## 方法升级

1. 每个深研项目精读至少 1 个核心模块，产出源码走读笔记
2. 同类项目横向对比（如 Envoy vs Nginx）
3. 贡献渐进：文档 → Bug 复现 → 小修复 → 小功能
4. 网站升级到动态技术栈（PostgreSQL + 后端 API）

## 完成标准

累计 300+ 卡片、23 篇深度剖析、10+ PR 被合并、9 个基金会百科、8 张图谱。
