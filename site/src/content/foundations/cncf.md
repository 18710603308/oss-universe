## 概述

云原生计算基金会（CNCF）是 Linux 基金会旗下专注云原生技术的子基金会，使命是「让云原生计算无处不在」。它是 Kubernetes 及其庞大生态的家园。

## 云原生的定义

CNCF 定义云原生 = **容器化 + 微服务 + 动态编排 + 声明式 API**，代表技术是容器、服务网格、不可变基础设施。

## 项目成熟度级别

```
Sandbox（沙箱）→ Incubating（孵化中）→ Graduated（毕业）
```

TiKV（PingCAP）、Harbor（VMware 中国团队）、KubeEdge（华为）、Dragonfly（阿里/蚂蚁）、OpenKruise（阿里）、Chaos Mesh（PingCAP）、Volcano（华为）等。

## 学习建议

CNCF 是云原生学习的绝对核心。路径建议：容器基础（Docker/containerd）→ Kubernetes 核心 → 周边生态（Helm/Prometheus/Envoy）→ 服务网格与 GitOps。CNCF Landscape 是一张必看的生态全景图。
