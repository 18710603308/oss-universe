## 概述

Apache 软件基金会是全球最大的开源基金会之一，秉持「社区优于代码（Community Over Code）」的理念，以精英治理和共识决策著称，其治理模式被称为「The Apache Way」。

## The Apache Way（阿帕奇之道）

1. **社区优于代码** — 健康的社区比代码本身更重要
2. **精英治理** — 基于贡献获得权限：Contributor → Committer → PMC Member
3. **共识决策** — 通过邮件列表投票（+1 / 0 / -1）
4. **开放透明** — 所有讨论在公开邮件列表进行
5. **独立中立** — 不受任何单一公司控制

## 项目生命周期

```
Apache Incubator（孵化器）→ Top-Level Project（顶级项目）
                                     ↓（不活跃）
                               Apache Attic（归档）
```

## 代表项目

- **大数据帝国**：Hadoop、Spark、Flink、Kafka、Hive、HBase、Airflow
- **Web/中间件**：HTTP Server、Tomcat、Dubbo、RocketMQ、APISIX
- **基础库**：Maven、Log4j、Commons、Lucene

## 中国贡献

Apache 是中国企业贡献顶级项目最多的基金会：Dubbo（阿里）、RocketMQ（阿里）、ShardingSphere（京东）、SkyWalking、DolphinScheduler、APISIX、Doris（百度）、IoTDB（清华）等。

## 学习建议

Apache 是理解「大数据」与「Java 中间件」生态的核心入口，建议从 Hadoop → Kafka → Spark/Flink 的脉络切入。
