## 概述

Linux 基金会是全球最具影响力的开源联盟，通过企业成员资助与专业项目管理，孵化和托管了 800+ 个开源项目，覆盖操作系统、云、网络、AI、区块链等几乎所有领域。

## 组织模式

采用「企业联盟资助 + 专业项目管理」模式，成员包括微软、Google、IBM、华为等 1000+ 企业。它旗下有众多子基金会。

## 主要子基金会与项目群

| 子基金会 | 领域 | 代表项目 |
|----------|------|----------|
| CNCF | 云原生 | Kubernetes, Prometheus |
| OpenJS Foundation | JavaScript | Node.js, jQuery, webpack |
| LF AI & Data | AI/数据 | ONNX, Milvus |
| Hyperledger | 区块链 | Fabric, Besu |
| OpenSSF | 安全 | Sigstore |
| RISC-V International | 芯片 | RISC-V 指令集 |
| PyTorch Foundation | AI | PyTorch |

## 直管项目

Linux 内核、Let's Encrypt、Xen、OCI（容器标准）等。

## 学习建议

Linux 基金会本身是一个「基金会的基金会」。理解它的价值在于把握开源的「组织形态」—— 大型开源项目如何通过中立基金会实现企业协作与可持续治理。
